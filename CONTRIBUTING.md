# Contributing

Work on a feature branch and keep changes reproducible. Before opening a pull
request, run the unit tests and document any change to data sources, aggregation
rules, grids, features, validation, or output metadata. Never commit downloaded
data, generated outputs, credentials, or provider-restricted material.

Changes to the frozen grid, SOMO35 definition, completeness thresholds, spatial
validation, or model-selection rule are methodology changes and must include a
rationale, tests, and an assessment of whether historical years need rebuilding.
